## 常用命令

**内核参数**（写 `/etc/sysctl.d/`，别写 `/etc/sysctl.conf`）

```shell
cat > /etc/sysctl.d/99-network.conf <<'EOF'
net.core.default_qdisc = fq
net.ipv4.tcp_congestion_control = bbr

net.ipv4.ip_forward = 1
net.ipv6.conf.all.forwarding = 1
net.ipv6.conf.default.forwarding = 1

net.ipv4.conf.all.rp_filter = 0
net.ipv4.conf.default.rp_filter = 0
net.ipv4.conf.*.rp_filter = 0
EOF

sysctl --system   # 只应用这一个文件：sysctl -p /etc/sysctl.d/99-network.conf
```

- `/etc/sysctl.conf` 在 Debian 13 上**开机根本不生效**：systemd 207 起 `systemd-sysctl` 只读 `/etc/sysctl.d`、`/run/sysctl.d`、`/usr/local/lib/sysctl.d`、`/usr/lib/sysctl.d`，Debian 也没建 `99-sysctl.conf → /etc/sysctl.conf` 那个兼容软链。往里 `echo ... >> /etc/sysctl.conf && sysctl -p` 只是当场生效，重启就丢。
- **文件名决定优先级**：所有目录下的文件跨目录按字典序合并，越靠后越优先（`/usr` 用 10–40，`/etc` 用 60–90）。Debian 自带 `/usr/lib/sysctl.d/50-default.conf`，里面已经有 `net.ipv4.conf.*.rp_filter = 2` 和 `-net.core.default_qdisc = fq_codel`，本地文件要 `99-` 这样的序号才盖得住。
- **`rp_filter` 光改 `all` 没用**：内核文档写明生效值取 `max(conf/all/rp_filter, conf/<接口>/rp_filter)`，每个接口也得改 —— `net.ipv4.conf.*.rp_filter` 就是干这个的（Debian 自己也在用）。通配符只在配置文件里有效：命令行 `sysctl -w 'net.ipv4.conf.*.rp_filter=0'` 不展开，直接报 `cannot stat .../conf/*/rp_filter`。
- **BBR 要配 `fq`**：内核 Kconfig 原文 “It requires the fq ("Fair Queue") pacing packet scheduler.”，少了 `net.core.default_qdisc = fq` 就退化成 TCP 自带的定时器 pacing。另外 `net.core.default_qdisc` 是全局参数（不在 netns 里），容器内 `/proc/sys/net/core/default_qdisc` 根本不存在，只能在宿主机改。
- **写不进去是静默的**：systemd-sysctl 对不存在的键只记 debug 日志、不算失败（`sysctl -p` 则会报错退出 1）；键名前加 `-` 表示失败也忽略，Debian 就是这么写的。配完读回来确认：

```shell
sysctl net.core.default_qdisc net.ipv4.tcp_congestion_control net.ipv4.ip_forward \
       net.ipv6.conf.all.forwarding net.ipv4.conf.eth0.rp_filter
```

**创建swap**

```shell
fallocate -l 2G /swap
dd if=/dev/zero of=/swap bs=1M count=2048

chmod 600 /swap
mkswap /swap
swapon /swap

free -h

nano /etc/fstab
/swap none swap sw 0 0
```
